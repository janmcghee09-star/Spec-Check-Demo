# Spec-Check Premortem Assistant

An AI-powered tool that analyzes Product Requirement Documents (PRDs) to identify potential risks, gaps, and edge cases before launch.

---

## 🎯 What It Does

Spec-Check uses Claude AI to conduct premortem analysis on your PRDs, identifying:
- 🔵 **Mental Model Issues** - Missing user context, unclear value props, behavioral assumptions
- 🟡 **Stakeholder Gaps** - Cross-functional alignment needs, teams to loop in
- 🔴 **Edge Cases** - Error states, failure modes, boundary conditions
- 🟢 **Metric Concerns** - Unclear success criteria, missing KPIs
